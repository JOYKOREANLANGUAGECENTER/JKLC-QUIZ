TTS 사용 안내

추천 방식

1) 직접 녹음 대신 브라우저 TTS

이 페이지는 브라우저의 내장 TTS 기능으로 한국어 단어를 바로 읽어줍니다. 별도 mp3를 하나씩 만들지 않아도 됩니다.

사용 방법

2) 가장 쉬운 사용 순서

① 음성 선택 → ② 속도 선택 → ③ 각 단어의 듣기 버튼 클릭

또는 현재 보이는 단어 전체 듣기로 한 번에 재생할 수 있습니다.

수업용 팁

3) 검색 + 카테고리 필터와 같이 사용

예를 들어 인사/표현만 선택한 뒤 전체 듣기를 누르면 인사말만 모아서 반복 학습할 수 있습니다.

주의

4) 음질은 기기마다 다를 수 있음

브라우저 TTS는 사용 중인 PC/휴대폰의 음성 엔진을 사용하므로, 기기마다 목소리와 자연스러움이 조금 다를 수 있습니다.

나중에 더 확장 가능

원하면 다음 단계로도 확장할 수 있습니다.

- 미얀마어 뜻까지 함께 읽기
- 자동 반복 재생
- 단어 카드 모드
- 퀴즈 모드
- 문장 100개 추가
- 외부 TTS 음원(mp3) 연결
